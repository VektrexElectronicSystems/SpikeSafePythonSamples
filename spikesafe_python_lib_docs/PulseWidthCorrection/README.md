## PulseWidthCorrection

### Definition
Calculates the pulse width correction argument for SpikeSafe's pulse width
adjustment algorithm. Use the class method with a populated `SpikeSafeInfo` object.

### Functions
| Name | Description |
| - | - |
| [get_optimum_pulse_width_correction](/spikesafe_python_lib_docs/PulseWidthCorrection/get_optimum_pulse_width_correction/README.md) | Returns a correction in microseconds as a string with three decimal places. |
